Flask Student Management Dashboard

A modern and user-friendly web application designed to simplify student, course, and user management. Built with Flask, SQLite, authentication, CRUD operations, and REST API support.

Get Started View Dashboard

Core Features

Secure Authentication

Register, log in, and securely manage access to protected pages with Flask-Login authentication.

Student Management

Add, view, update, and delete student records with an organized and easy-to-use interface.

Course Management

Manage courses efficiently and connect them with students through structured database relationships.

REST API & Testing

Access application resources through API endpoints and validate functionality with a Flask testing suite.

About This Project

This application was developed as a capstone project to demonstrate full-stack backend and web development skills using Flask. It follows a modular architecture with blueprints, supports database operations, authentication workflows, HTML + Jinja templates, and RESTful APIs.

Technologies Used

Flask SQLite SQLAlchemy Flask-Login Flask-Migrate Jinja2 HTML/CSS REST API Pytest
